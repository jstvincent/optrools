# API Changelog 33.4.0 vs. 34.2.0


## API Changes

### GET /audit_survey_templates
-  added the optional property `audit_survey_templates/items/scopes` to the response with the `200` status


### POST /audit_survey_templates
-  added the new optional request property `audit_survey _template/scopes`
-  added the optional property `audit_survey_templates/items/scopes` to the response with the `200` status


### DELETE /audit_survey_templates/{audit_survey_template_id}

### GET /audit_survey_templates/{audit_survey_template_id}
-  added the optional property `scopes` to the response with the `200` status


### PUT /audit_survey_templates/{audit_survey_template_id}
