# API Changelog 35.0.0 vs. 35.1.0


## API Changes

### GET /global_audits/{global_audit_id}
-  added the enum value `workflowAutomationRule` to the property `items/` of the `query` request parameter `include`


### GET /issue_categories
-  added the optional property `issue_categories/items/detail_smart_form_template_id` to the response with the `200` status
-  added the optional property `issue_categories/items/is_detail_schema_form_enabled` to the response with the `200` status


### POST /issue_categories
-  added the new optional request property `issue_category/detail_smart_form_template_id`
-  added the new optional request property `issue_category/is_detail_schema_form_enabled`
-  added the optional property `issue_categories/items/detail_smart_form_template_id` to the response with the `200` status
-  added the optional property `issue_categories/items/is_detail_schema_form_enabled` to the response with the `200` status


### DELETE /issue_categories/{issue_category_id}
-  added the optional property `detail_smart_form_template_id` to the response with the `200` status
-  added the optional property `is_detail_schema_form_enabled` to the response with the `200` status


### GET /issue_categories/{issue_category_id}
-  added the optional property `detail_smart_form_template_id` to the response with the `200` status
-  added the optional property `is_detail_schema_form_enabled` to the response with the `200` status


### PUT /issue_categories/{issue_category_id}
-  added the new optional request property `allOf[#/components/schemas/issue_categories_put]/issue_category/detail_smart_form_template_id`
-  added the new optional request property `allOf[#/components/schemas/issue_categories_put]/issue_category/is_detail_schema_form_enabled`
-  added the new optional request property `allOf[#/components/schemas/issue_categories_put]/previous_values/detail_smart_form_template_id`
-  added the new optional request property `allOf[#/components/schemas/issue_categories_put]/previous_values/is_detail_schema_form_enabled`
-  added the optional property `detail_smart_form_template_id` to the response with the `200` status
-  added the optional property `is_detail_schema_form_enabled` to the response with the `200` status


### GET /timesheet_entries
-  added the required property `timesheet_entries/items/week_of` to the response with the `200` status


### POST /timesheet_entries
- :warning: added the new required request property `timesheet_entry/week_of`
-  added the required property `timesheet_entries/items/week_of` to the response with the `200` status


### DELETE /timesheet_entries/{timesheet_entry_id}
-  added the required property `week_of` to the response with the `200` status


### GET /timesheet_entries/{timesheet_entry_id}
-  added the required property `week_of` to the response with the `200` status


### PUT /timesheet_entries/{timesheet_entry_id}
- :warning: added the new required request property `allOf[#/components/schemas/timesheet_entries_put]/timesheet_entry/week_of`
-  added the new optional request property `allOf[#/components/schemas/timesheet_entries_put]/previous_values/week_of`
-  added the required property `week_of` to the response with the `200` status
