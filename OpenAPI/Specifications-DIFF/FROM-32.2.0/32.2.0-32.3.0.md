# API Changelog 32.2.0 vs. 32.3.0


## API Changes

### GET /audit_survey_templates
-  added the enum value `auditSurveys` to the property `items/` of the `query` request parameter `include`


### GET /audit_survey_templates/{audit_survey_template_id}
-  added the enum value `auditSurveys` to the property `items/` of the `query` request parameter `include`


### GET /framework_items
-  added the optional property `framework_items/items/framework_requirement_level_id` to the response with the `200` status


### POST /framework_items
-  added the new optional request property `framework_item/framework_requirement_level_id`
-  added the optional property `framework_items/items/framework_requirement_level_id` to the response with the `200` status


### DELETE /framework_items/{framework_item_id}
-  added the optional property `framework_requirement_level_id` to the response with the `200` status


### GET /framework_items/{framework_item_id}
-  added the enum value `frameworkRequirementLevel` to the property `items/` of the `query` request parameter `include`
-  added the optional property `framework_requirement_level_id` to the response with the `200` status


### PUT /framework_items/{framework_item_id}
-  added the new optional request property `allOf[#/components/schemas/framework_items_put]/framework_item/framework_requirement_level_id`
-  added the new optional request property `allOf[#/components/schemas/framework_items_put]/previous_values/framework_requirement_level_id`
-  added the optional property `framework_requirement_level_id` to the response with the `200` status


### GET /global_audits/{global_audit_id}
-  added the enum value `markupFileTieSubmission` to the property `items/` of the `query` request parameter `include`
