# API Changelog 27.3.0 vs. 28.0.0


## API Changes

### GET /audit_surveys
-  added the enum value `riskAcceptanceProposal` to the property `items/` of the `query` request parameter `include`


### GET /audit_surveys/{audit_survey_id}
-  added the enum value `riskAcceptanceProposal` to the property `items/` of the `query` request parameter `include`


### GET /comments
- :warning: removed the enum value `regulationItem` from the property `items/` of the `query` request parameter `include`
-  added the enum value `versionChangeTask` to the property `items/` of the `query` request parameter `include`


### GET /comments/{comment_id}
- :warning: removed the enum value `regulationItem` from the property `items/` of the `query` request parameter `include`
-  added the enum value `versionChangeTask` to the property `items/` of the `query` request parameter `include`


### GET /rcw_requests
-  added the optional property `rcw_requests/items/has_evidence_files` to the response with the `200` status
-  added the optional property `rcw_requests/items/has_reference_files` to the response with the `200` status


### POST /rcw_requests
-  added the new optional request property `rcw_request/has_evidence_files`
-  added the new optional request property `rcw_request/has_reference_files`
-  added the optional property `rcw_requests/items/has_evidence_files` to the response with the `200` status
-  added the optional property `rcw_requests/items/has_reference_files` to the response with the `200` status


### DELETE /rcw_requests/{rcw_request_id}
-  added the optional property `has_evidence_files` to the response with the `200` status
-  added the optional property `has_reference_files` to the response with the `200` status


### GET /rcw_requests/{rcw_request_id}
-  added the optional property `has_evidence_files` to the response with the `200` status
-  added the optional property `has_reference_files` to the response with the `200` status


### PUT /rcw_requests/{rcw_request_id}
-  added the new optional request property `allOf[#/components/schemas/rcw_requests_put]/previous_values/has_evidence_files`
-  added the new optional request property `allOf[#/components/schemas/rcw_requests_put]/previous_values/has_reference_files`
-  added the new optional request property `allOf[#/components/schemas/rcw_requests_put]/rcw_request/has_evidence_files`
-  added the new optional request property `allOf[#/components/schemas/rcw_requests_put]/rcw_request/has_reference_files`
-  added the optional property `has_evidence_files` to the response with the `200` status
-  added the optional property `has_reference_files` to the response with the `200` status
