# API Changelog 33.0.0 vs. 33.1.0


## API Changes

### GET /audit_surveys
-  added the enum value `requestingParty` to the property `items/` of the `query` request parameter `include`
-  added the optional property `audit_surveys/items/requesting_party_id` to the response with the `200` status


### DELETE /audit_surveys/{audit_survey_id}
-  added the optional property `requesting_party_id` to the response with the `200` status


### GET /audit_surveys/{audit_survey_id}
-  added the enum value `requestingParty` to the property `items/` of the `query` request parameter `include`
-  added the optional property `requesting_party_id` to the response with the `200` status


### PUT /audit_surveys/{audit_survey_id}
-  added the new optional request property `allOf[#/components/schemas/audit_surveys_put]/audit_survey/requesting_party_id`
-  added the new optional request property `allOf[#/components/schemas/audit_surveys_put]/previous_values/requesting_party_id`
-  added the optional property `requesting_party_id` to the response with the `200` status


### GET /global_audits/{global_audit_id}
-  added the enum value `scoreCardBracket` to the property `items/` of the `query` request parameter `include`
-  added the enum value `shareRecipient` to the property `items/` of the `query` request parameter `include`
