# API Changelog 27.2.0 vs. 27.3.0


## API Changes

### GET /auditable_entities
-  added the optional property `auditable_entities/items/external_resource_id` to the response with the `200` status
-  added the optional property `auditable_entities/items/inherent_risk_calc` to the response with the `200` status


### POST /auditable_entities
-  added the new optional request property `auditable_entity/external_resource_id`
-  added the new optional request property `auditable_entity/inherent_risk_calc`
-  added the optional property `auditable_entities/items/external_resource_id` to the response with the `200` status
-  added the optional property `auditable_entities/items/inherent_risk_calc` to the response with the `200` status


### DELETE /auditable_entities/{auditable_entity_id}

-  added the optional property `inherent_risk_calc` to the response with the `200` status
