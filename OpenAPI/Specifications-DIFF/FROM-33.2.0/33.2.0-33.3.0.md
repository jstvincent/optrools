# API Changelog 33.2.0 vs. 33.3.0


## API Changes

### GET /action_plans
-  added the enum value `scenarioItem` to the property `items/` of the `query` request parameter `include`
-  added the optional property `action_plans/items/cost_to_execute` to the response with the `200` status
-  added the optional property `action_plans/items/deferred_action` to the response with the `200` status
-  added the optional property `action_plans/items/scenario_item_id` to the response with the `200` status


### POST /action_plans
-  added the new optional request property `action_plan/cost_to_execute`
-  added the new optional request property `action_plan/deferred_action`
-  added the new optional request property `action_plan/scenario_item_id`
-  added the optional property `action_plans/items/cost_to_execute` to the response with the `200` status
-  added the optional property `action_plans/items/deferred_action` to the response with the `200` status
-  added the optional property `action_plans/items/scenario_item_id` to the response with the `200` status


### DELETE /action_plans/{action_plan_id}
-  added the optional property `cost_to_execute` to the response with the `200` status
-  added the optional property `deferred_action` to the response with the `200` status
-  added the optional property `scenario_item_id` to the response with the `200` status


### GET /action_plans/{action_plan_id}

-  added the optional property `cost_to_execute` to the response with the `200` status
