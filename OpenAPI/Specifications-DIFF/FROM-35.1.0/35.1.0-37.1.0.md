# API Changelog 35.1.0 vs. 37.1.0


## API Changes

### GET /files
- :warning: removed the required property `files/items/tags` from the response with the `200` status


### POST /files
- :warning: added the new required request property `file/file_tags`
- :warning: removed the required property `files/items/tags` from the response with the `200` status
- :warning: removed the request property `file/tags`


### DELETE /files/{file_id}
- :warning: removed the required property `tags` from the response with the `200` status


### GET /files/{file_id}
- :warning: removed the required property `tags` from the response with the `200` status


### PUT /files/{file_id}
- :warning: added the new required request property `/allOf[#/components/schemas/files_put]/file/file_tags`
- :warning: removed the required property `tags` from the response with the `200` status
- :warning: removed the request property `/allOf[#/components/schemas/files_put]/file/tags`
- :warning: removed the request property `/allOf[#/components/schemas/files_put]/previous_values/tags`


### POST /upload_files/{upload_file_id}/complete
- :warning: removed the required property `files/items/tags` from the response with the `200` status
