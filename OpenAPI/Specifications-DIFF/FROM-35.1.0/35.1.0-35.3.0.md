# API Changelog 35.1.0 vs. 35.3.0


## API Changes

### GET /action_plans
- :warning: removed the enum value `scenarioItem` from the property `items/` of the `query` request parameter `include`
-  added the enum value `scenarioItems` to the property `items/` of the `query` request parameter `include`


### GET /action_plans/{action_plan_id}
- :warning: removed the enum value `scenarioItem` from the property `items/` of the `query` request parameter `include`
-  added the enum value `scenarioItems` to the property `items/` of the `query` request parameter `include`


### GET /auditable_entities
-  added the enum value `inheritedWeights` to the property `items/` of the `query` request parameter `include`
-  added the enum value `riskPosture` to the property `items/` of the `query` request parameter `include`
-  added the enum value `weightGroups` to the property `items/` of the `query` request parameter `include`
-  added the enum value `weights` to the property `items/` of the `query` request parameter `include`
-  added the optional property `auditable_entities/items/risk_posture_id` to the response with the `200` status


### POST /auditable_entities
-  added the new optional request property `auditable_entity/risk_posture_id`
-  added the optional property `auditable_entities/items/risk_posture_id` to the response with the `200` status


### DELETE /auditable_entities/{auditable_entity_id}
-  added the optional property `risk_posture_id` to the response with the `200` status


### GET /auditable_entities/{auditable_entity_id}
-  added the enum value `inheritedWeights` to the property `items/` of the `query` request parameter `include`
-  added the enum value `riskPosture` to the property `items/` of the `query` request parameter `include`
-  added the enum value `weightGroups` to the property `items/` of the `query` request parameter `include`
-  added the enum value `weights` to the property `items/` of the `query` request parameter `include`
-  added the optional property `risk_posture_id` to the response with the `200` status


### PUT /auditable_entities/{auditable_entity_id}
-  added the new optional request property `allOf[#/components/schemas/auditable_entities_put]/auditable_entity/risk_posture_id`
-  added the new optional request property `allOf[#/components/schemas/auditable_entities_put]/previous_values/risk_posture_id`
-  added the optional property `risk_posture_id` to the response with the `200` status


### GET /global_audits/{global_audit_id}
-  added the enum value `knowledgeLibraryAnswer` to the property `items/` of the `query` request parameter `include`
-  added the enum value `knowledgeLibraryQuestion` to the property `items/` of the `query` request parameter `include`


### GET /risks
-  added the enum value `inheritedWeights` to the property `items/` of the `query` request parameter `include`
-  added the enum value `weightGroups` to the property `items/` of the `query` request parameter `include`
-  added the enum value `weights` to the property `items/` of the `query` request parameter `include`


### GET /risks/{risk_id}
-  added the enum value `inheritedWeights` to the property `items/` of the `query` request parameter `include`
-  added the enum value `weightGroups` to the property `items/` of the `query` request parameter `include`
