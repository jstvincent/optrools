# API Changelog 30.3.0 vs. 31.0.0


## API Changes

### GET /audit_surveys
-  added the enum value `auditSurveyBundle` to the property `items/` of the `query` request parameter `include`
-  added the optional property `audit_surveys/items/audit_survey_bundle_id` to the response with the `200` status


### DELETE /audit_surveys/{audit_survey_id}
-  added the optional property `audit_survey_bundle_id` to the response with the `200` status


### GET /audit_surveys/{audit_survey_id}
-  added the enum value `auditSurveyBundle` to the property `items/` of the `query` request parameter `include`
-  added the optional property `audit_survey_bundle_id` to the response with the `200` status


### PUT /audit_surveys/{audit_survey_id}
-  added the new optional request property `allOf[#/components/schemas/audit_surveys_put]/audit_survey/audit_survey_bundle_id`
-  added the new optional request property `allOf[#/components/schemas/audit_surveys_put]/previous_values/audit_survey_bundle_id`
-  added the optional property `audit_survey_bundle_id` to the response with the `200` status


### GET /entities
-  added the optional property `entities/items/migration_logs` to the response with the `200` status


### POST /entities
-  added the new optional request property `entity/migration_logs`
-  added the optional property `entities/items/migration_logs` to the response with the `200` status


### DELETE /entities/{entity_id}
-  added the optional property `migration_logs` to the response with the `200` status


### GET /entities/{entity_id}
-  added the optional property `migration_logs` to the response with the `200` status


### PUT /entities/{entity_id}
-  added the new optional request property `allOf[#/components/schemas/entities_put]/entity/migration_logs`
-  added the new optional request property `allOf[#/components/schemas/entities_put]/previous_values/migration_logs`
-  added the optional property `migration_logs` to the response with the `200` status


### GET /framework_items/{framework_item_id}
-  added the enum value `gapAssessmentTasks` to the property `items/` of the `query` request parameter `include`


### GET /global_audits/{global_audit_id}
- :warning: removed the enum value `auditSurveyBundleTaskGroup` from the property `items/` of the `query` request parameter `include`
-  added the enum value `contentMappingSuggestion` to the property `items/` of the `query` request parameter `include`
-  added the enum value `contentMappingSuggestionMetadatum` to the property `items/` of the `query` request parameter `include`
-  added the enum value `gapAssessmentTask` to the property `items/` of the `query` request parameter `include`
-  added the enum value `monitorBracket` to the property `items/` of the `query` request parameter `include`
-  added the enum value `siteOwner` to the property `items/` of the `query` request parameter `include`
