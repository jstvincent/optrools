# API Changelog 31.2.0 vs. 31.3.0


## API Changes

### GET /global_audits/{global_audit_id}
-  added the enum value `citation` to the property `items/` of the `query` request parameter `include`


### GET /issues
-  added the enum value `citations` to the property `items/` of the `query` request parameter `include`


### GET /issues/{issue_id}
-  added the enum value `citations` to the property `items/` of the `query` request parameter `include`


### GET /risks
-  added the enum value `suggestions` to the property `items/` of the `query` request parameter `include`


### GET /risks/{risk_id}
-  added the enum value `suggestions` to the property `items/` of the `query` request parameter `include`


### GET /teams
-  added the enum value `siteOwner` to the property `items/` of the `query` request parameter `include`


### GET /teams/{team_id}
-  added the enum value `siteOwner` to the property `items/` of the `query` request parameter `include`


### GET /users
-  added the optional property `users/items/scim_external_id` to the response with the `200` status


### POST /users
-  added the new optional request property `user/scim_external_id`
-  added the optional property `users/items/scim_external_id` to the response with the `200` status


### POST /users/external_api_token
-  added the optional property `users/items/scim_external_id` to the response with the `200` status


### DELETE /users/{user_id}
-  added the optional property `scim_external_id` to the response with the `200` status


### GET /users/{user_id}
-  added the optional property `scim_external_id` to the response with the `200` status


### PUT /users/{user_id}
-  added the new optional request property `allOf[#/components/schemas/users_put]/previous_values/scim_external_id`
-  added the new optional request property `allOf[#/components/schemas/users_put]/user/scim_external_id`
-  added the optional property `scim_external_id` to the response with the `200` status
