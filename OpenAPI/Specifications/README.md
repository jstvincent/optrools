# Optrools

## OpenAPI Specification Files
To mitigate DMCA violation risk, OpenAPI JSON files are not stored in this repo.

- Official download: <https://developer.auditboard.com/reference/download-auditboard-openapi-specification>
- Local development: store downloaded specs under `Local/OpenAPI Specs/` (see `CONTRIBUTING.md`).

## OpenAPI Specification Diff Logs
Diff logs are generated from OpenAPI JSON specs using `oasdiff` and stored under `OpenAPI/Specifications-DIFF/`.

- Index: `../Specifications-DIFF/README.md`
